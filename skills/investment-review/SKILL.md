# 投资复盘：把炒股变成长本事的过程，而不是赌消息的过程

## 先立规矩（开场即适用，先说清再干活）

1. **不荐股、不预测价格、不给"该不该买/卖"的结论**。原因直说：无投顾资质；AI 的买卖结论不构成任何依据；国内"荐股"是持牌业务（只有证监会许可的证券投资咨询机构能做）。
2. 被问"该不该买/卖"时：**给问题清单，不给答案**——按下面「做功课流程」列出该核实的事实、该想清楚的问题，判断权永远在用户。
3. 输出分三层，不得混淆：**事实**（附一手来源）/ **知识**（有出处的通识）/ **流程建议**（怎么做功课、怎么复盘）。三层之外不编。
4. 用户情绪化时（兴奋、焦虑、想加仓回本）：不助推交易冲动，先回到流程和复盘。

## 一、事实核查流程（"这公司什么来头"）

输入一个代码或名字：

1. 确认身份：全名、代码、交易所。**曾用名是关键**（更名常伴随重组/易主）。查交易所官网或巨潮资讯网（cninfo.com.cn）的 F10/公告区。
2. 关键事实清单（每项去公告里对，不复述媒体）：
   - 曾用名 / ST 历史（*ST=退市风险警示，ST=其他风险警示，摘帽=撤销）
   - 控制权、实控人变更（近三年）
   - 主营业务变更（跨界/转型公告）
   - 减持、质押、定增、重组类公告（近一年）
   - 业绩预告 / 定期报告里敢写出来的数字
   - 股票交易异常波动公告（交易所要求发的 = 波动被盯上了）
3. **信源分级（硬 → 软）**：交易所/公司公告 > 监管问询函及回复 > 券商研报（看谁写的、有无利益关系）> 财经媒体 > 自媒体/群聊/口口相传。**转述永远按最低档处理**，包括"朋友/同学/老师"。
4. 输出：事实列表，每条附来源链接；查不到就直说查不到。

行情与公开新闻：优先用 WebSearch 或交易所/公司公告页；抓取被拦时换数据源或走代理。不要用群聊截图当一手信息。

## 二、复盘流程（"总结经验"的正规名字就是它）

日志位置：默认 `~/My_Skills/02_Insights/炒股复盘日志.md`（append-only，每条带日期）；可用环境变量 `INVEST_LOG` 指向别处。没有这个文件就先建，不把复盘结果只留在对话里。

每笔交易记这些（买卖前后都可以复）：

1. 标的 / 日期 / 方向 / 仓位
2. **买入理由**：一句话说清。信息来源是谁、属于哪一级
3. **事前可核实但没核实的事实**（复盘的核心：不审结果，找流程漏洞）
4. **预设的证伪条件**：什么情况出现就说明买错了？（买入时没写 = 如实记"没写"）
5. 情绪记录：当时什么状态
6. **归因**：赚/亏分别属于"流程对 / 流程错 / 纯运气"哪一种——归因错，经验就是负的
7. **落一条规则**：下次要怎么做——能执行、能检查的一条

复盘原则：只审流程，不审运气；不因赚钱就认可一次烂流程，也不因亏钱就否定一次好流程。

## 三、认坑模式库（看到类似描述先拉警报）

- 群里/直播间"老师"免费讲票 → 拉人收会员费 / 抬轿子出货
- "原始股""即将上市""内部额度"
- "内幕消息""主力要拉"
- 网上认识的"高手/学姐/大师"带你投资（杀猪盘标准开场）
- 代客理财、包赚不赔、稳赚高收益
- 配资/高杠杆、"借你账户用一下"

处理：不转账、不点链接、不交账户；怀疑被骗拨 96110（反诈）或 110；机构资质去证监会官网查（12386 热线）。

## 四、概念随问随讲

*ST/摘帽、借壳/重组、商誉、定增、减持、质押、换手率、龙虎榜……问哪个讲哪个：先一句人话定义，再讲"它为什么存在、对决策意味着什么"，能举真实近例就举。只讲机制，不借概念暗示涨跌。

系统学习可选：把课程笔记放在 `~/My_Skills/02_Insights/炒股入门/`（README = 课程表与进度）。随问随讲时对照进度：已学过的简答即可，未学过的别超纲展开。

## 边界

- 不构成投资建议；不替用户下任何买卖决定。
- 大额决策找持牌机构/专业人士。
- 炒股知识类 B 站视频 → 交给 bili-learn 按 2星/3星 处理，与本日志互相挂链。
