# 踩坑池（继承，别重新踩）

> 从 `new-project/SKILL.md` 拆出来的。**开工前扫一眼标题就够**，遇到具体问题再查对应条目。
> 新坑按 🔴🟡🟢 分级记入**当前项目**的 `project.md` 踩坑节；跨项目通用的再补到这里。

遇到新坑按 🔴🟡🟢 分级记入 project.md 踩坑节。**以下是从既往项目继承的已知坑，遇到直接跳过：**

- **编码**（中文 Windows）：
  - `.bat` 必须 **GBK + CRLF**（cmd 按代码页解析，UTF-8 中文注释会被当命令执行）
  - `.ps1` 必须 **UTF-8 带 BOM**（PS 5.1 否则按 GBK 解析中文报错）
  - 写文件用 Write 工具默认 UTF-8 会踩坑，bat 需另存 GBK
- **中文路径**：cv2.imread 等读不了中文路径 → 临时文件用 ASCII 名
- **模板驱动**：要"像官方"就打开官方模板读-填-写，**绝不重建**（样式全丢）；模板的 run/下划线/空格结构就是布局，改内容不动结构
- **独立重算**：任何已有计算值都要从源头数据重算验证，不信表内值（防"自洽但错"）
- **测试先清默认数据**：默认示例行可能恰好凑对数值，掩盖 bug（0.10+0.10=0.20 巧合）
- **catch 吞错误 = 静默失败**：调试期把错误暴露出来，别让用户看到"点了没反应"
- **OCR 小图不可靠**：用结构类比 + 数学自洽 + 像素分析交叉验证
- **网络**：raw.githubusercontent.com 被重置 → 用 api.github.com contents API；国内装 Electron 用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`；必要时请求用户开启代理
- **pip/pipx 装包慢或挂**（pypi.org 直连 ~5s 龟速被工具杀）→ 一律加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`（实测 2s）
- **代理开着 ≠ 终端代理生效**：只开浏览器代理对 curl/pip 无效；部分代理模式下国内站反而秒级 000 被拒 → 装包用镜像不赌代理；诊断用 `curl -w "%{http_code} %{time_total}s"`（000+<1s=被拒,200+慢=勉强通）
- **Bash 长命令结果丢失**（Claude Code internal error,pip 安装类易触发）→ 输出落盘 `> log 2>&1` + run_in_background + 轮询；**结果丢了先读日志确认事实,别盲目重试**
- **Windows 装 CLI 后 exe 不在 PATH**：winget 写注册表(本会话不生效)、Python Scripts 目录常需手动补；改 User PATH 用 `[Environment]::SetEnvironmentVariable('Path',$new,'User')`,别用 setx 拼接
- **pipx/venv 内改第三方源码** = 升级静默还原 → 源码注释必须留日期 + 配套提供幂等重打脚本
- **AI 字幕转写的平台/数字名不可信**：识别视频里项目靠口播关键词 ↔ README 逐句对照 + 星数时间线,不信字幕名单
- **中文 shell**：Git Bash heredoc 里含反引号/中文会炸 → 先 Write 脚本文件再执行
- **去重语义**：统计/计费类先实测去重倍数（同 message.id 多条记录会 3.6x 多算），再写逻辑
- **交付分享包/发布包前必须查夹带，而且要查「包」不是查「源目录」**：
  - **程序被运行过就会在自己的目录里生成状态文件** —— 本项目分享版跑一次后，`core/.stats-cache.json`（3.7MB）就出现在包里，内含**完整本地路径、会话 UUID、逐条 token 用量**。而 zip 是打包那一刻的快照，目录和 zip 状态可能不一致，**必须解开 zip 逐条列**。
  - **凭据类要实际 grep，不能靠「设计上不在」**。本项目的 key/token 全在用户主目录（`~/.claude/settings.json`、`~/.ds-sync-token.json`），项目里本不该有 —— 实测确认无真值，但匹配到的会是**读令牌的代码**（变量名 `ANTHROPIC_AUTH_TOKEN`、`userToken`），**别被假阳性吓到，也别因为看到一堆匹配就以为查完了**：要单独跑一次「真值型模式」（`sk-[A-Za-z0-9]{20,}`、`Bearer <长串>`）才算数。
  - **规则固化进代码**：把自检写成打包脚本里的断言（缺 settings.json / 图标 / Electron 本体、或夹带 stats-cache 就抛错），而不是写在文档里靠自觉。
  - 顺带查个人信息（用户名、`C:\Users\` 绝对路径）有没有硬编码进源码。
- **工具选型**：`tar` 在 git-bash 里是 GNU tar，**会把 `C:\...` 当远程主机、也读不了 zip**；要列 zip 内容用 Windows 自带的 `System32\tar.exe`（bsdtar），从 Node 用 `execFileSync` 传参（不经 shell，中文路径安全）。PowerShell 读 zip 也行，但路径不能写在 .ps1 里（见上一条编码坑）。
- **动态生成的 DOM，监听器必须就地绑定**：先 `buildSlots()` 造元素、却在加载时提前 `$('ev_'+k).addEventListener(...)`，拿到 `null` 抛错后**整段脚本静默中断**（后面所有初始化都不执行），表现只是「界面一片空白、值全是占位符」——看不出跟那行有关
- **量「自然高度」要解开容器约束**：`head.offsetHeight + body.scrollHeight` 在内容不溢出时 `scrollHeight === clientHeight`，而后者是从窗口高度反推的 —— 量到的是「窗口现在多高」而不是「内容需要多高」，于是**每次打开设置窗就长 2px，无限累积**。临时把容器 `height:auto` 再量
- **删文件前先看里面有没有用户数据**：清测试状态时 `rm settings.json`，把用户自己设的角色图一起删了（那个文件装着 base64）。清状态前先确认内容，或只删真正程序独占的状态文件
- **git-bash 会把 `/flag` 当路径转换**：`csc.exe /nologo` → `C:/Program Files/Git/nologo`。命令行开关一律用 `-` 前缀（`-nologo`）。**没有短横线写法的命令一样中招**：`taskkill /PID 123 /T /F` 里 `/PID` 被拆成 `C:/Program Files/Git/PID`，报「无效参数」。杀进程树改用 PowerShell 的 `Stop-Process`（或 `taskkill //PID`）
- **一次性脚本直接写纯 ASCII**：.ps1 走 bash heredoc 或 Write 工具都是 UTF-8 无 BOM，PowerShell 按 GBK 读会把中文串的行尾引号吞掉 → 解析失败。临时脚本的注释和输出标签用英文，不折腾 BOM（长期留在项目里的 .ps1 才值得上 BOM）。**别以为只有注释和输出会中招——`param()` 默认值里的中文路径同样被压坏**（实测默认值 `...-分享版.zip` 变成 `...-分享?.zip` 直接找不到文件）。路径含中文时改成运行时自动发现（列目录 + 按大小/时间筛），别写进脚本字面量
- **`will-change: transform` 别乱加**：它把元素提升成独立合成层，若该元素位于祖先的 `preserve-3d` / `perspective` 上下文内，**每帧都要在 3D 空间里重新光栅化** —— 实测一张 104×92 的图片做 12.6 秒位移动画，峰值吃掉 **300% CPU**（约 30ms/帧）。加之前先量；摘掉后同一个动画降到忽略不计。详见 `案例库.md` 的「性能问题怎么查」
- **Claude Code 权限分类器会拦 `-ExecutionPolicy Bypass`**（判为「削弱安全控制」，直接拒执行）。本地 .ps1 用默认执行策略就能跑，**不需要也不该随手加 Bypass**；写进文档的使用示例里也别带它
- **改成「更好」之前先问是不是用户本来就要的**：把用户认可的合成音换成自制 WAV 后被打回（「原来的更好听」）；把日期从 `2026-09-15` 收成 `09-15` 是我自作主张（虽然换来了更大的角色图）。**顺手改的东西要单独说，别混在「修 bug」里交付**
- **先调研技术方案再动手，不要默认选一个工具直接开干**：
  - DS Phone Agent 项目：用户说"把 zip 编译成 APK"，我直接选了 Buildozer 开干，没有先查"DS 手机版有没有现成方案 / 国内怎么做的"。结果硬刚了 Buildozer + p4a 一整座冰山——pip 兼容、SDK 路径、子模块超时、Looper 异常——全是自己趟出来的。
  - **正确做法**：接到任务先搜方案（GitHub / 国内论坛 / 官方仓库），列出 3-5 个候选路线写优缺点对比，让用户选方向。方向错越努力越糟，方向对再面对具体技术坑。
  - **报错先搜已知解**：遇到报错先搜 issue / Stack Overflow / 中文博客，不闷头硬刚。SDK 安装问题、pip 兼容问题等大概率别人踩过。
- **优先级表的 `.get(k, 默认值)` —— 默认值不能是"中间值"**（2026-09-18 归档项目）：源优先级写成 `SRC_RANK = {"综测小组":0, …, "微信文件":3}` + `SRC_RANK.get(src, 9)`。**没登记的源（社会实践/实习llz/奖状）拿到 9，反而"输给"微信的 3** → 重复组的「保留版」被选成微信那份（缓存，会被清），本地那份被丢进待删。**差点真丢内容，而且全程不报错。** 正解：`99 if src == "微信文件" else SRC_RANK.get(src, 1)` —— **默认值取"最差"，危险的源显式钉死在最末。**
- **分组键别取一级目录 —— 拍平层级 = 丢关系**（2026-09-18 归档项目）：扫目录出清单时取 `rel.parts[0]` 当分组键，子目录被摊平。`正式推免\05a-排名证明.pdf`（终版）和 `_推免工作区\05a-排名证明.docx`（工作稿）并排列出，**用户看到就说「还是有冗余」** —— 一条信息没少，丢的是「这两个是什么关系」。**任何"扫目录出清单"的任务，分组键用完整相对目录路径。**
- **用户的陈述是假设，不是事实 —— 既不能不信，也不能照做**（2026-09-18）：①「微信里对我有用的本地都存了」→ 实测 489 个候选里本地只有 195 个，**294 个只在微信里**（按印象跳过会丢 64 个个人材料，且不报错）；②「那个工作计划书其实可以删掉」→ 实测大作业文件夹里**没有**这份，删了就真没了（正解是**挪位置不销毁**）。**用户指的方向通常是对的，但数量级和后果要用脚本量。**
- **`shutil.copy2` 会连只读属性一起复制**：微信缓存文件多为只读，`copy2` 进归档后 `unlink()` 报 `WinError 5 拒绝访问`，表现为「明明是我的文件却删不掉」。删之前先 `os.chmod(p, stat.S_IWRITE)`。
- **`Path.stem` 对多点文件名是错的**：`Path("zjm.skill").stem == "zjm"`（`.skill` 被当扩展名），于是 `zjm.skill.zip` 和 `zjm.skill` 目录匹配不上、重复进列表。**判「同名」要用全名减掉压缩包后缀比，别用 stem。**
- **反斜杠会被吃掉两层**：工具调用的 JSON 一层 + bash heredoc 一层，`\\` 传到 Python 手里变成 `\`，导致生成的 JS 里出现非法 `'\'`（SyntaxError）、补丁脚本 `SyntaxError`。**同一处改了三遍才成。解法不是「再数一层转义」，是换不含该字符的写法**（`String.fromCharCode(92)` / `chr(92)`），或改用单层的 Write/Edit 工具直接落盘（与上面「heredoc 会炸 → 先 Write 脚本文件」同源）。
- **交付带链接的 HTML 之前，先想清楚「点了会发生什么」**：浏览器**不能**把本地文件交给系统默认程序 —— `.docx/.xlsx` 会**下一份副本**；`file:///目录` 会让浏览器**导航走**去显示自己的文件列表（用户原话：「点开文件夹后回不到这个索引网页了」）。**「点一下就打开」这件事 xlsx 才是对的工具**（Excel 把路径交给系统）；非要用网页，就得注册自定义协议（归档项目的 `zzopen:`：只写 `HKCU\Software\Classes`、不需要管理员、可 `--uninstall` 完全还原、浏览器不发生导航）。
- **HF 模型下载（国内）三件套**（2026-09-18 音视频项目）：①`HF_ENDPOINT=https://hf-mirror.com` 必须在 **import huggingface_hub 之前**设——它在 import 时读一次定死，设晚了直连 huggingface.co 超时；②hf-mirror 代理不了 xet 协议 → 必须 `HF_HUB_DISABLE_XET=1`，否则下载 401；③模型下完先 `du -sh` 缓存目录再断言「就位」，别信"没报错"。
- **CUDA「能加载 ≠ 能算」**：ctranslate2 等 GPU 推理库设备初始化成功，真跑到 encode 才报 `cublas64_12.dll is not found` → `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`，并把 `site-packages\nvidia\*\bin` 挂进 DLL 搜索路径（`os.add_dll_directory` + PATH）。**验证必须跑到"真吐出一个结果"为止。**
- **Windows 杀进程三件套**（凡 spawn 长任务必读）：①`python` 等命令可能是**启动器套娃**（PyManager / WindowsApps stub）——`c.pid` 是"壳"，杀它杀不到真身（孙子进程活着：文件锁死、改名 EBUSY、`close` 事件永不来）；②被杀进程的句柄要过一拍才释放 → 改名/删除要**退避重试**（EBUSY/EPERM）；③兜底 = **按命令行标记杀**（标记取任务唯一目录名；.ps1 -File 调 powershell 并回读 DEAD/ALIVE）。
- **PowerShell 调用规范**：bash 里内联 `-Command "多语句…"` 过 argv 会炸（空输出/exit 255）→ 一律写成 `.ps1` 文件用 `-File` + 具名参数；**脚本里按命令行匹配进程时必须排除自身**（`$_.ProcessId -ne $PID`）——脚本自己的命令行带着参数，不排除会自杀、末段检查还会永远误报 ALIVE。
- **推理模型 API 的 max_tokens**（deepseek-flash 等）：额度会被 reasoning_tokens 吃光→正文为空；给足（≥8k~16k）并**用 finish_reason 判定成败**（stop=完成 / length=被截断），别只看有没有报错。
- **whisper 系中文转写**：默认可能出繁体/乱标点 → `initial_prompt='以下是普通话的句子。'`（实测相似度 0.53→0.89）；黑话/术语用「词表注入」（terms.txt 一行一词，拼进 initial_prompt）压同音错字。
- **长任务的「停止」= 立刻停 + 明确反馈**（2026-09-18 用户实测打回两次）：别把"停止后继续处理"做成停止键的主行为；「停止（停下并交付已得）｜中止（全停）」两段式要显式分设；点完必须有视觉变化（按钮变形/计时/阶段文字），否则用户体感=「点了没用」。
- **模型名不能按命名规律推断能力**（2026-09-19 音视频项目）：小米 `mimo-v2.5-pro` 名字像升级版，实际是**纯文本**，发图返回 `404 No endpoints found that support image input` —— 不是「参数错误」那种好认的报错；多模态是 `mimo-v2.5`（不带 pro）。**接多模态 API 前先实测一张图**，别按名字推断。
- **「当前生效的配置」≠「全部配置」**（2026-09-19）：cc-switch 把各供应商的 key 存在自己的 SQLite（`~/.cc-switch/cc-switch.db`）里，`~/.claude/settings.json` 只有**当前激活**那一家。要调非当前供应商，必须按名字去它自己的库取 —— 拿 settings.json 的 token 打别家端点必然 401，而且极易被误读成「key 失效」。
- **计量字段可能只是「部分值」**（2026-09-19）：Anthropic 形状的 `usage.input_tokens` 是**未命中缓存**的增量、不是总量，要再加 `cache_read_input_tokens`（实测 `36` + `768`）。只读前者会把成本少算一个数量级。
- **比价先看 token 构成，再看单价表**（2026-09-19）：同一张图、两个模型价目表接近，实际每帧成本差 **3.9 倍** —— 差距全在推理 token（输出 718~922 里 **664~877 是推理**，正文只剩三四十）。关闭开关往往存在：`reasoning_effort: "none"` 有效，**`"minimal"` 无效**（仍烧 552），`thinking:{"type":"disabled"}` 也有效。**先问「能不能关推理」，再比单价。**
- **功能「没生效」先区分「没送到」和「送到了但被正确忽略」**（2026-09-19）：画面描述并进会议纪要后，模型判断与议题无关、一条没采纳 —— 只看输出会误判成功能坏了。**验证要测输入侧**（上下文 token 涨没涨），或构造一个必然相关的用例。
- **量到 0 先排除「量错了对象」**（2026-09-19）：DOM 尺寸为 0 可能是元素真被藏了，也可能它的父页面被切走了 —— 程序化触发尤其容易中招（点一个隐藏页面上的按钮照样生效）。**先确认观测上下文，再下结论。**
- **CDP `Runtime.evaluate` 在同一个全局上下文反复求值**（2026-09-19）：裸的 `const x = ...` 第一拍能跑，**第二拍报 `Identifier 'x' has already been declared`**，症状是「只有第一次采样有值，后面全 undefined」。多语句包 IIFE；且**观测脚本必须打印异常正文** —— 压成一句「报错」能把根因瞒好几轮采样。
- **改了步骤顺序，回头查收尾/清理逻辑**（2026-09-19）：把「抽帧」从「总结」之后挪到之前后，原本「抽帧结束即收工」的清理变成**任务中途误清状态**（界面把进行中卡片整个藏掉）。顺序变更的连带影响多在收尾路径上，不在主流程。同类：清空任务队列时要**兑现挂起的 Promise**，否则 await 方永远挂住。
- **本机特有：腾讯电脑管家 × Defender「半残废」冲突**（2026-09-18 实测）：管家接管后 Defender 的 `webthreatdefusersvc` 仍自动启动 → 每 ~3 分钟一批「服务意外终止」→ 会话/explorer 重启（表现：屏幕闪黑 + 「此电脑」弹窗 + 窗口被关）。排查：`Get-WinEvent -FilterHashtable @{LogName='System'; Id=7031}` 看崩溃节奏；`Get-Process explorer | Select StartTime` 看壳层是否刚重启。与业务项目无关；**管家开/关切换的瞬间也会触发一次**。
- **fpdf2 中文排版三坑**（2026-10-02 ai项目·推免材料）：
  - `multi_cell` **默认两端对齐（Align.J）** → 中文被拉出怪异空隙；正文/标题一律显式 `align="L"`。要真两端对齐：按剩余宽度**均摊字距**（`set_char_spacing`，非末行），右缘齐平且不留空格缝
  - 自带换行会把 **CJK 标点甩到行首**（「。」起行）；`WrapMode.CHAR` 与 `set_text_shaping(True)`（uharfbuzz）都治不了；U+2060 粘连符方案在字体缺字形时**会整段丢字**（实测丢「件、」等）。正解 = 自写禁则换行（标点不起行、开括号不结尾、英文词不拆），实现见 `ai项目/scripts/build_pdf.py`
  - 字体：`msyh.ttc` / `simsun.ttc` 可直接 `add_font`，加载时 "MERG NOT subset" 警告无害
- **无头浏览器截图三件事**（2026-10-02 ai项目）：
  - 同一台机器 **curl / Python / 浏览器 的网络能力可能彼此不同**（实测 curl 全死、Python 全通、Edge 半通）→ 抓资源用 Python，渲染截图用浏览器，各用各的强项
  - `python -m http.server` 在后台起不来（连接拒绝）→ 本地渲染走 `file://`（跨文件读取加 `--allow-file-access-from-files`，或把数据内嵌进 HTML）
  - `--headless=new` + `--virtual-time-budget` 组合会挂死 → 用 `--headless` + `--timeout`；等 SPA 数据加载完再截用 `--virtual-time-budget`（旧模式下正常）；CDP 连 `--remote-debugging-port` 会 403 → 客户端 `suppress_origin=True` 或服务端加 `--remote-allow-origins`
- **zip 文件名乱码修复**（2026-10-02 ai项目）：zip 缺 UTF-8 标志位时 Python 按 cp437 解码 → `name.encode('cp437').decode('utf-8')` 还原（**不是 gbk**；gbk 会解码失败、留下乱码文件名）
