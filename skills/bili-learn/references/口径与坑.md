## 口径明细

- **级别由用户拍板**，skill 只出「建议级别 + 理由」（可勾清单模式）
- **0 星清理**是改 B 站账号的动作：出清单 → 用户勾 → 可撤销执行；永不自动
- **多账号**：按账号分别配置凭证。公开视频的转录/元数据用任意登录凭证即可；**只有扫收藏夹**才需要对应账号凭证
- **缓存 vs 资产**：`bili-learn\data\` 随时可删（快照/克隆可重建）；`<知识库目录>/My_Skills/` 是长期资产，备份只备它
- **首页/索引单一数据源**：各条目 README 首部「一句话」字段是唯一源，INDEX.md / 未来面板 / 脚本都从它汇总

## 坑池

- **2026-10-12 AI 字幕会语义错配**：BV1wwa86KER8 的"字幕"内容是英雄联盟比赛解说（1.14.2 文档承认这是已知限制：同语言语义不符是"已接受"的）。→ 转录后**必做**标题/简介关键词交集体检，不通过按无字幕处理
- **2026-10-12 音译错字 ≠ 语义错配（体检过了也别直接用）**：正确视频的 AI 字幕专有名词会大面积同音错译（实测 Agent→"A景"、Harness→"海利士"、token→"拖更"、git→"get it"、spec→"space"、E2E→"1to1"、Fable5→"飞博五"）→ 按上下文还原、拿不准不硬编，产出文末附「音译还原表」（样板：Agent岗面试要点 README）
- **2026-10-12 收藏夹 API 跳过失效视频**：单页可能 <20 条，**不能用「不足 20 条 = 最后一页」**；翻页判据用 `has_more` 字段（踩过：544 只抓到 92）
- **2026-10-12 工具链类视频的真知识在仓库不在视频**：评论区"营销号味道"是常态噪音，别被带偏；定级看仓库质量（文档/测试/CI），不看视频观感
- **2026-10-12 MCP 版本差**：1.9.0 无收藏夹遍历工具、无 ASR 参数；批量扫描一律走自家脚本（零 token），别用 MCP 逐页翻
- **2026-10-12 换缓存的判断**：仓库 clone / npm 包解包 / 快照 JSON 全在 `data\`，处理完可删；删除前先确认知识已进 `My_Skills\`（替身活着才删源）
- **2026-10-12 GitHub 直连抖 + WebFetch 被拦**（已修）：终端 curl/git 直连吃 GFW 抖动（raw 时通时断 reset、clone 断流）；WebFetch 对 github 系域名报 "Unable to verify…"（校验链路被墙，**弃用**）→ GitHub 素材一律走本地工具（git / curl / mcp fetch）。**解法**：本地代理 `127.0.0.1:<端口>`（若绑 0.0.0.0，netstat 用 127.0.0.1 过滤会漏）；可配 `git config --global http.https://github.com.proxy http://127.0.0.1:<端口>`（仅 github.com 生效）；手动 curl 加 `-x http://127.0.0.1:<端口>`；mcp fetch 带 `proxy` 参数传同值。**代理换端口/关闭 → git 配置失效，unset 后重设**。账号与墙无关：clone/raw/releases 零账号可用
- **2026-10-15 npm 直连 npmjs 会卡死**：`npx` 首次拉包实测 180s 超时（playwright-mcp 安装时踩到）；与 B 站无关，但**排队的 MCP 升级会撞上** → 全局安装/升级一律加 `--registry=https://registry.npmmirror.com`（实测 2 秒装完）
- **2026-10-18 “订阅转 API”不是开放 API**：WorkBuddy/DSH 插件复用桌面登录态（加密凭据 + token 刷新 + 官方客户端头），渠道会做客户端校验，别把“OpenAI 兼容”当成通用授权入口
- **2026-10-18 第三方 DSH 桌面版是 fork**：`salathleizhang/deepseek-harness-desktop` 是魔改版；官方是 `deepseek-ai/deepseek-harness`，GitHub Releases 没有预编译 Windows 安装包，日常用 `npx @deepseek-ai/dsh web` 或源码构建。装前先看 `.git/config` 的 remote，别把 fork 当官方
- **2026-10-18 Windows 删 DSH/大目录**：git-bash 里 `cmd //c rmdir` 会被路径转换搞坏（实测报 “Q:”），用 PowerShell `Remove-Item -LiteralPath ... -Recurse -Force`；删 `~/.dsh` 前先删 `skills` 链接（指向源目录），否则可能连目标一起删；DSH_HOME 可指到 D，npm 全局留 C（MCP 启动器依赖），源码/构建放 D
- **2026-10-19 规则文本自己会复现被禁句式**：写「AI 垃圾文风」避雷清单时，边界说明连用 3 处「不是 X，而是 Y」，✅ 示例还保留小剧场。→ 产出规则/清单后，拿清单回扫自己，再交付
- **2026-10-19 浏览器扩展 ≠ 系统代理**：ilink 只作用于 Edge 进程；Playwright 独立配置默认带 `--disable-extensions`，装扩展不生效 → 要复用登录态/代理用 `--extension` 连现有 Edge；token 从扩展状态页复制，别从截图抄（`O/0`、`n` 易混）
