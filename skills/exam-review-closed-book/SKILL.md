# 闭卷简答题复习资料生成

## 调用方式

用户说：按闭卷简答题整理 / 生成模拟简答题集 / 帮我整理 XX 课的闭卷复习资料。

## 适用场景

- 大学期末闭卷，题型为简答题（不考公式计算）；
- 老师出题风格：考查零件/总成的**作用、原理、特点、对比**；
- 已有资料：教材 PDF + 往届复习文档（docx）+ 老师口头划重点；
- 目标：可直接背诵的模拟题集 + 补全旧的背诵资料。

## 工作流程（6 步）

### 第 1 步：提取现有资料

```python
# docx
from docx import Document
doc = Document('复习资料.docx')
txt = '\n'.join([p.text for p in doc.paragraphs])

# pdf
import fitz
doc = fitz.open('教材.pdf')
txt = ''.join([page.get_text() for page in doc])
```

### 第 2 步：收集老师口头重点

向用户确认：考试范围（哪几章）、每章具体重点（XX 的功用/原理/特点/对比）、老师特别强调的"小点"（某参数范围、某数字）。

### 第 3 步：对照检查现有资料

用正则逐项扫描，输出对照表：

```
知识点              背诵资料  概论文档
Ch1 五条基准线       ✅        ✅
Ch1 整车整备质量m₀   ❌        ✅
Ch2 后备系数β        ✅        ❌
```

### 第 4 步：生成模拟简答题集（核心产物）

- 每章 3~7 题，全卷 40~50 题；
- 题型严格按老师风格：作用/原理/特点/对比；
- 每题配完整答案（分点列举 + 关键词突出）；
- 末尾附"复习提示与答题技巧"；
- 输出 docx。

### 第 5 步：补全旧背诵资料

按第 3 步缺口表，把缺失章节/知识点插入旧版文档，保持原有版式，同步更新所有相关文件。

### 第 6 步：验证

跑脚本确认知识点正则全部命中、章节数量核对、文件大小确认。

## 输出文件

| 文件 | 定位 |
|---|---|
| `模拟简答题集.docx` | 主复习资料，直接背诵 |
| `背诵知识点_vN.docx` | 精简版知识点手册 |
| `各章概论_vN.docx` | 每章概述与设计要求 |

## 出题规律（优先级从高到低）

1. **对比类**："XX 与 YY 在结构/效率/适用上有什么区别？"
2. **特点类**："膜片弹簧为什么是主流？有哪些优点？"
3. **功用类**："离合器的主要功用是什么？"
4. **原理类**："三轴式变速器的直接档为什么效率最高？"
5. **设计要求类**："XX 设计应满足哪些基本要求？"
6. **参数类**："β 的取值范围是多少？选取原则是什么？"

## Word 版式

- 题目：红色粗体【题N】
- 答案："答："绿色粗体，正文黑色
- 分点用 • 符号缩进
- 章节标题蓝色黑体
- 表格浅色网格
- 章节间分隔线 ━━━
- 正文宋体 11.5 pt，1.5 倍行距
- 复习提示用楷体灰色小字

## 记忆辅助（可选）

用户需要时额外生成：关键词填空自测表（挖空答案关键词）、一句话考点卡片（每题浓缩一句）、全书数字串记（"5线 4功用 10要求 β1.2-4…"）。

## 与彩色重点版的区别

| 维度 | 彩色重点版 | 本 skill |
|---|---|---|
| 资料源 | PPT 优先 | docx/PDF 为主 |
| 输出 | 分层精讲教材 | 模拟简答题集 |
| 目标 | 系统理解 | 直接背题应试 |
| 格式 | 彩色底纹+导图 | 红绿题号+分点答案 |
| 章节结构 | 导图→知识点→考题预测 | 章节→题目→答案 |
| 适用 | PPT 完善的课 | 只有资料+老师口述的闭卷 |
